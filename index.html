Accessible Periodic Table of Elements

An interactive periodic table with full keyboard navigation and screen reader support.

How to Use

  • Tab - Navigate to the first element (Hydrogen), then use arrow keys
  • Arrow Keys (←↑→↓) - Navigate between elements in the grid
  • Enter or Space - View detailed information about an element
  • Escape - Close the information modal
  • Click any element to view its details
